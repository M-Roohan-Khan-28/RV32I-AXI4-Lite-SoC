# Waveforms

The recorded simulation waveform is [integration.vcd](../logs/integration.vcd).
Open it in a VCD viewer to inspect the store/load sequence. The readable trace is
in [soc_integration_test.log](../logs/soc_integration_test.log).

PNG screenshots have not been captured yet. This folder is intended for exports
from the actual simulation, with signal names and a readable time scale.
